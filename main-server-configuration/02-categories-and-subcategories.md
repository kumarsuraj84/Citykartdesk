# Categories & Sub-Categories

Source: `/admin/categories` on Main (mirrored into Local), captured 2026-09-24. Schema: `service_categories` + `service_sub_categories` tables. Each category is tagged "FOR X TEMPLATE USE" meaning it's offered on that Form Template's category picker; a service pulls in categories via its own tagging (see `01-services.md`).

This is the real, live category taxonomy used across HR, IT, Admin (repair/requirement/AC), VM (visual merchandising), BD (business development/facilities), L&D, Legal, LP, PO Advice, and Finance workflows. Sub-categories are listed in full since this is exactly the kind of detail another AI would need to understand what requesters can actually select.
