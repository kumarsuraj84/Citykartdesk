# What each ticket status means

| Status | Meaning |
|---|---|
| Open | New, or reopened, or waiting for a technician. |
| Assigned | A technician has been named; work has not started. |
| In Progress | Work has started. |
| Waiting on User | The technician needs something from you. **Reply in the conversation** and the ticket continues. The service clock is paused. |
| Hold due to Purchase from HO | The technician is waiting for a purchase from head office. Only the technician can start or end this hold. The service clock is paused. |
| Pending Approval | An approval is open. The service clock is paused until it is decided. |
| Resolved | The technician says it is fixed. You can reopen it within the reopen window. |
| Closed | Final. |
| Cancelled | Final (a ticket cancelled because an approval was rejected can be reopened within 48 hours). |
